Authentication

Register

Registers the user and returns an access token. Token must be generated securely and be longer than 32 characters.

Request Body schema: application/json
required
username
required
string

Must be unique. Must be at least 3 characters.

password
required
string

Must be at least 6 characters.

password_confirmation
required
string

Must match the password field.

Responses

http://localhost/api/v1/auth/register

Request samples

  • Payload
Content type
application/json
{
  • "username": "johndoe",
  • "password": "secret123",
  • "password_confirmation": "secret123"
}

Response samples

  • 201
  • 422
Content type
application/json
{
  • "token": "a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4e5",
  • "role": "USER"
}

Events

List Events

Returns a paginated list of events. Supports optional filtering by date and search by title or location.

Authorizations:
default
query Parameters
page
integer
Example: page=1

Page number (default: 1).

date
string
Example: date=2026-05-01

Filter by event_date (YYYY-MM-DD).

search
string
Example: search=Almaty

Search substring in title or location.

Responses

http://localhost/api/v1/events

Response samples

  • 200
  • 401
Content type
application/json
{
  • "data": [
    • {
      • "id": 1,
      • "title": "string",
      • "description": "string",
      • "location": "string",
      • "event_date": "2026-05-01",
      • "capacity": 100,
      • "registrations_count": 10
      }
    ],
  • "meta": {
    • "current_page": 1,
    • "last_page": 1,
    • "per_page": 10,
    • "total": 1
    }
}
